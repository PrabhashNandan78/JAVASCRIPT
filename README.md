Located in `.devcontainer/01.basics/`:

- `01.variables.js` — declaring variables with `const`, `let`, and `var`, an assignment without a declaration keyword (`accountCity`), and printing a value with `console.log`

## Development environment

`.devcontainer/devcontainer.json` configures a Node.js dev container (image: `mcr.microsoft.com/devcontainers/javascript-node:1-22-bookworm`), so the files can be opened and run in a containerised Node.js environment.
